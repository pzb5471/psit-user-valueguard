# 交付单进程本机网页应用

开发环境中，React、TypeScript 和 Vite 前端使用独立开发服务器，并通过代理访问 FastAPI。交付环境先构建前端静态资源，再由 FastAPI 同一进程提供页面、REST API 和经过授权的案例图片。SQLite 与运行数据保存在本机；使用一个启动命令启动一个服务进程，默认只监听 `127.0.0.1:8000`。成员发生端口冲突时可以显式覆盖端口，但系统不得随机换号或改为非回环监听。

本机浏览器访问的仍是真实网页产品：批次导入、GLM 调用、状态更新、案例详情、人工确认和持久读回都实际执行。v1 不加入 Docker、Redis、反向代理、HTTPS、登录系统、局域网多人访问或公网云部署。这些能力只有部署范围改变时才进入新设计。

单机方案不能支持多用户并发和机器故障后的远程恢复，但与当前 Mock 数据、单一运营角色、最多 20 个案例和 10 天交付范围一致。直接做公网部署会同时引入身份认证、密钥保护、传输安全、运维和备份要求，无法视为单纯“生成一个网页链接”。
