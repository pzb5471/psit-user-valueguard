# 业务页面只呈现结果投影

九张表、状态枚举、运行编号、数据版本和模型调用记录都属于内部设计，不是产品展示内容。业务页面除完成操作必需的待分析、分析中、待人工确认、已完成、处理异常五种状态和可处理错误外，只回答三个问题：谁是高价值客户、为什么存在流失风险、应该怎么做。

案例队列只呈现脱敏客户标识、高价值客户标识、风险摘要、系统建议介入等级、排序理由、业务状态和必要异常标记。案例详情按高价值结论、流失风险原因、处理建议、按需展开的业务证据与不确定性、人工确认组织。事件、情绪和多模态判断可以成为风险原因的依据，但页面不使用感知、归因、策略、RFM 或其他技术阶段名称组织内容。

RFM 计算过程、分数、分位、权重、阈值、数据库字段、内部整数 ID、运行编号、数据版本、Schema、Agent 分工、Prompt、Token、供应商响应、模型调用、技术日志和原始 JSON 不进入业务响应 DTO，也不出现在页面。批次、案例和证据文本标识只在路由、关联和必要错误定位中使用，不作为核心业务内容突出展示。

完全隐藏证据会使运营人员无法核验 AI 判断，因此“只呈现结果”不等于只显示一句结论。关键证据和不确定性仍可按需展开，但呈现的是业务事实，不解释系统采用了什么算法。
