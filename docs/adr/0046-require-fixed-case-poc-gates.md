# 用固定案例硬门槛判定模型路线是否可用

> 演讲版 MVP 的双人复核条款已由 ADR 0087 取代；固定 15 案例、45 阶段和全部自动质量边界继续有效。

GLM-5.3-Flash 接口能够返回内容，不等于已经达到可用 MVP。正式 PoC 必须完整运行固定 10 个演示案例和密封 5 个验收案例，共 45 个阶段结果。选定配置首次结构通过不少于 41 个，使用允许的一次定向修复后 45 个全部通过；不得出现不存在或跨案例的证据、目录外动作、隐藏答案字段或密封答案泄漏。

5 个密封案例必须全部满足关键事实不编造、证据支持主要原因、不确定性诚实、介入等级符合程序规则、动作在批准目录内，并由两名验收者一致判断可作为人工决策初稿。两个图片贡献案例和一个行为贡献案例均须达到规定差异。默认并发 2 时，第一个完整案例在 2 分钟内出现，10 个演示案例在 10 分钟内完成，且不得持续出现 HTTP 429 或 SQLite 写入错误。

任一门槛未通过，模型路线不得标记为可用，也不得冻结为正式配置。这些指标只证明当前固定案例达到可用 MVP 门槛，不代表生产准确率、真实留存效果或企业部署能力。
