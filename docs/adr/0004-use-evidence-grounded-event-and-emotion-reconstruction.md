# 采用有证据的事件与情绪还原

情感感知的核心输出采用有证据的事件与情绪还原，不采用“情感倾向 + 情绪强度分数”作为完整结果。系统需要说明客户经历了什么、当前情绪可能是什么，并区分事实、推断、冲突和缺口。

当前数据中可用的人工参考情绪只有平静和不耐烦，因此 `PerceptionResult` 的当前情绪只允许平静、不耐烦、无法判断，并保存一句解释、客户文本证据和按需出现的不确定性。情绪变化、目标情绪和独立备选解释数组不进入 v1 必填合同。情绪判断以客户文本为依据；图片和行为数据可以支持事件事实，但不能用于猜测客户情绪。该决定牺牲了更丰富的情绪结构，换取与现有数据一致、可人工复核且更容易稳定生成的合同。
