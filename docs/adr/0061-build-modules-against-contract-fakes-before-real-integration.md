# 先按合同替身开发，再接入真实模块

四个模块若等待上游实现完成才开始工作，就无法真正并行；若各自猜测接口，到最后再补接口，则会形成四块单独能跑但无法组合的代码。

功能实现前先冻结 M1—M3、M2—M3 和 M3—M4 三组合同。M1 使用固定 ZIP 与临时 SQLite，M2 使用固定分析输入与测试模型客户端，M3 使用 `FakeDataGateway` 和 `FakeAnalysisEngine`，M4 使用 MSW。替身和真实适配器必须通过相同合同测试。

替身只能替换相邻模块边界，不得直接跳过上传、校验、状态机、持久化或页面读回。真实接线时通过依赖注入替换适配器，不修改调用方业务流程迎合实现。
