# Agent 负责语义判断，确定性程序负责计算和校验

MVP 采用“Agent 判断，程序校验”的组合方式。确定性程序负责聚合付款记录、计算履约事实和 RFM、检查输入缺失、控制案例级数据访问、校验结构化输出、核对证据引用、阻止隐藏答案进入运行环境，并执行介入等级最低要求和策略范围的硬约束。感知 Agent 只从当前案例对话和图片中提取可观察事实；归因 Agent 选择受控风险原因并给出证据、反证和不确定性；策略 Agent 在版本化动作目录范围内提出介入等级和最多三项处理动作。

Agent 输出不直接成为最终系统结果。程序先检查必填字段、枚举值、证据 ID、原因类别、策略动作和禁用内容；不合格结果进入受控重试，重复失败后转为处理异常或人工核验。可信但可能严重的问题即使证据不足，也不能因为置信度低而自动归为暂不介入。Strategy Agent 给出的等级低于固定最低要求时，程序直接采用最低允许等级并记录调整原因，不再次调用模型，也不修改 Agent 给出的风险原因和处理方案。

该方案拒绝两个极端：完全由规则处理会失去对自然语言和图片的理解能力；完全由 Agent 决定会导致结果漂移、证据缺失和越权动作。组合方案增加了合同和校验代码，但换来稳定、可追溯、可测试和可人工纠正的运行结果。
