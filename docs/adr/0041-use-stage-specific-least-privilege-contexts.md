# 三个 Agent 使用阶段专属的最小上下文

感知 Agent 只读取当前案例客户对话、售后图片、经过固定案例人工核验的订单状态和履约事实、`case_id` 与可引用证据编号。它不读取高价值客户结论、RFM、风险答案、动作目录、其他案例或密封验收答案，避免客户价值先验夸大事件与情绪。

归因 Agent 读取 `PerceptionResult`、其中实际引用的客户文本和订单事实、图片观察及证据编号。它不重复接收原始图片，也不读取高价值结论、RFM、动作目录和策略结果。风险原因只由当前售后事实支持，不由客户价值倒推。

策略 Agent 读取 `PerceptionResult`、`AttributionResult`、高价值客户结论、获准证据编号、`action_catalog.v1.json` 和介入等级最低规则。它不读取原始图片、完整原始对话、RFM 过程、其他案例或验收答案。高价值结论只允许影响介入优先级和处理方式。

源数据没有币种且当前交易、对话、图片是 Mock 映射，付款金额保留用于内部追溯，不发送给模型。三个阶段的实际输入清单必须可在测试中检查，但不进入业务页面。
