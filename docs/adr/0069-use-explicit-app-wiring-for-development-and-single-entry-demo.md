# 显式装配开发模式和单入口演示模式

四个模块需要在开发时独立替换，演示时又必须通过一个本机入口稳定运行。隐藏的全局单例和自动 Fake 回退会使实际使用的模块无法确认，并可能把测试结果冒充真实分析。

M3 使用应用工厂显式注入 M1 端口和 M2 引擎。`scripts/dev.ps1` 按同一已校验端口配置启动 FastAPI 与 Vite，支持热更新和测试配置；`scripts/start.ps1` 验证当前前端构建或按需重建，完成运行目录、端口与单实例校验，只在真实数据库迁移前生成一致性备份，并由 FastAPI 同时提供 `/api/v1` 和当前前端文件。应用与数据库就绪后才可以打开一次浏览器，`scripts/stop.ps1` 通过当前实例专属本机请求复用正常关闭流程，不增加 HTTP 关机接口。

演示模式不依赖 Docker 或 Vite，不允许 Fake 和测试模型。缺少 `ZAI_API_KEY` 时保留真实工作台与历史读取，只将分析能力标为不可用，不自动换成假模型。
