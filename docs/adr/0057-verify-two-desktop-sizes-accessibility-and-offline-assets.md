# 验收两种桌面尺寸、可访问性和离线资源

本期是本机桌面 MVP，不做手机端，但“只在开发者大屏上能用”仍然属于演示级实现。网络依赖、键盘不可达、低对比度和 1024px 页面溢出都会直接阻断真实操作。

批次导入、案例队列和案例详情必须在 `1366×768` 与 `1024×768` 完成全部主流程和完整状态验收。页面主体不横向滚动，1024px 下只允许表格局部滚动；主要点击区域不小于 44×44px，键盘可完成核心操作，文字与控件达到 WCAG AA。

字体、图标和必要页面资源随产品本地打包，断网时保持可用。本期不做手机端、平板专用布局或双主题，也不允许 CDN、颜色单一表达、混合图标族或只验证正常状态。
