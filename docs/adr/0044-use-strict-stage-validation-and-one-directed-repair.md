# 使用严格阶段校验和一次定向修复

每次模型响应依次通过 JSON 解析、Pydantic 严格字段、枚举、`case_id`、`evidence_id` 归属、跨阶段引用、禁用内容和阶段程序规则校验。Pydantic 禁止额外字段，不对字符串、列表和数字进行宽松自动转换。Agent 只能引用当前案例、当前阶段获准使用的证据编号。

归因引用必须来自感知阶段允许传递的证据；策略动作必须属于当前动作目录且最多三项，沟通重点最多三项。策略给出的介入等级低于程序最低要求时，程序直接提高并记录原因，不新增模型调用，也不改写风险原因和处理动作。

模型已经返回但结构或硬规则不合格时，只允许一次定向修复。修复请求使用相同阶段上下文，附带原始错误输出和明确校验错误，不增加证据、不读取验收答案。结构合格但业务仍有不确定性时进入人工确认，不因为主观偏好自动重新采样。
