# 使用单 ZIP、两步导入和数据推导的大小上限

MVP 通过工作台导入已经整理好的 Mock 数据。导入后自动分析会让用户来不及确认内容并产生意外模型费用；随意猜测上传大小上限则可能拒绝正式演示包，或放大资源消耗风险。

浏览器每次只上传一个 ZIP，“导入并校验”与“开始批量分析”保持分离。导入结果显示文件名、案例数、证据数、校验结论和 Mock 标记。浏览器只快速检查扩展名、空文件和配置大小，FastAPI 承担全部权威校验。

固定演示包形成后，以最大合格 ZIP 实际大小约两倍并向上取整，写入 `upload.max_zip_bytes`；前后端测试读取同一配置含义。不采用未经数据支持的 50 MB 或 100 MB 默认值，不允许前端校验绕过后端合同。
