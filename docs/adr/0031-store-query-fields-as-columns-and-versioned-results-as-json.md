# 查询字段成列，版本化完整结果存 JSON

需要查询、排序、去重或建立数据库约束的标识、版本、状态、脱敏客户标识、高价值结论、系统与人工介入等级、批次计数、时间、校验值、相对路径和当前版本引用使用独立列。当前源数据没有售后案例创建时间、消息时间、币种和行为比较窗口，数据库不得为了表面完整增加这些业务字段。

`CaseInput v1`、`PerceptionResult`、`AttributionResult`、`DecisionPackage`、人工修改内容、模型原始响应、结构校验错误和技术错误详情按各自版本合同整体保存为 JSON。队列页面不从 JSON 中计算排序字段，JSON 也不作为跨表关系的替代品。

当前状态、进度计数、开始结束时间、`current_case_run_id` 和 `current_review_id` 允许更新。已形成的阶段结果、模型调用、已结束案例运行、人工确认和失败详情只追加、不覆盖。案例重跑完成后，在同一个数据库事务中保存新结果并切换当前指针；事务失败时指针保持旧值。
