# 冻结五状态案例生命周期

案例需要区分尚未开始、正在处理、等待人工、完成和技术异常。若为每个内部 Agent 阶段增加页面状态，用户会看到技术实现；若证据不足进入异常，又会混淆业务未知与系统故障。

案例业务状态固定为 `PENDING_ANALYSIS`、`ANALYZING`、`PENDING_REVIEW`、`COMPLETED`、`PROCESSING_ERROR`。完整结果，包括诚实的证据不足结果，进入待人工确认；技术失败和程序中断进入处理异常。待人工确认和处理异常可人工重跑，已完成是不可重跑的终态。

不增加停止、暂停、恢复和 Agent 阶段业务状态。所有允许和禁止转换由单一状态机和参数化测试约束。
