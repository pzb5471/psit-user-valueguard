# 使用受校验的 TOML 配置和环境变量密钥

非敏感运行参数统一保存在进入 Git 的 `config/default.toml`，成员电脑的显式覆盖保存在不入 Git 的可选 `config/local.toml`，两者由 `pydantic-settings` 在启动时严格合并和校验，至少覆盖模型、重试、执行器、前端轮询、存储目录、端口和日志。配置项缺失、类型错误或超出范围时立即停止启动并指出具体项目，不使用隐式默认值带错运行，也不静默更换目录或端口。

智谱密钥只从 `ZAI_API_KEY` 环境变量读取，不进入源码、Prompt、TOML、数据库业务字段、日志或页面。`.env` 不进入 Git，`.env.example` 只列变量名和说明。缺少密钥时，工作台和数据库仍可启动并读取历史结果，但开始分析和重新分析不可用。

`/health` 分别报告应用、数据库和分析服务是否就绪，不返回密钥内容、供应商原始响应或本机绝对路径。业务页面只显示用户能够处理的状态和下一步，不展示模型配置细节。
