# 通过归属受控的标识提供证据文件

案例详情通过 `batch_id`、`case_id` 和 `evidence_id` 请求图片。后端先确认批次和案例关系，再确认该证据属于当前案例、解析后的文件位于正式批次目录，最后依据文件真实内容返回媒体类型。业务响应和页面不得包含本机绝对路径，也不接受路径作为证据读取参数。

第一版只支持现有数据实际包含的 JPG、JPEG、PNG 和 GIF。GIF 在页面展示原文件，模型分析继续使用组包阶段提取的静态首帧。ZIP 中出现绝对路径、`../` 路径穿越、符号链接或解压目标越过批次临时目录时，整个批次拒绝导入。

直接开放上传目录实现更快，但会让错误 evidence_id、恶意压缩包或路径拼接读取到不属于当前案例的文件。受控接口增加一次归属检查，却能同时满足证据展示、刷新读回、错误定位和文件安全。
