# 使用有限 HTTP 状态集合和统一业务错误

FastAPI 默认校验错误、程序异常、ZIP 错误和业务冲突如果各自返回不同结构，M4 必须为每条接口重复解析，也容易把技术信息带到页面。

v1 只使用 200、201、202、400、404、409、413、415、422、503 和 500，并按固定含义映射。所有 JSON 错误统一为 `BusinessError`，包含稳定编号、中文摘要、失败对象、业务阶段、下一步和 `trace_id`。FastAPI 默认 422 与 500 也必须转换。

不把供应商状态码直接透传给页面，不返回 HTML 错误页、自由文本异常或第二套错误外壳。
