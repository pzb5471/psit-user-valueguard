# 投影当前有效结果和被引用的业务证据

案例未完成人工确认时，队列和详情采用当前 `case_run` 的系统建议。人工确认后采用人工最终结果；如果人工修改过系统建议，页面默认显示人工结果，并允许在折叠的“查看系统原建议”中查看原业务建议和修改原因。人工直接通过时不重复展示两份相同内容。

`CaseQueueItemView` 只包含路由所需案例标识、脱敏客户标识、高价值标识、流失风险原因摘要、当前有效介入等级、排序理由、五种业务状态和必要异常标记。案例详情只按高价值结论、流失风险原因、处理建议、按需关键证据与不确定性、人工确认组织。

证据区默认只投影当前结果实际引用的客户对话、售后图片、订单与客户价值事实。页面可以说明证据支持或冲突了哪项判断，显示实际缺失、不确定性和必要的 Mock 模拟关联标记；不返回证据内部编号、哈希、文件路径、内部身份字段、来源 JSON、RFM 过程和模型参数。
