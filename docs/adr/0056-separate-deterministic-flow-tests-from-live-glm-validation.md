# 分开确定性产品流程测试和真实 GLM 验证

每次前端或端到端测试都调用真实模型，会带来费用、延迟和不稳定结果；只用固定返回值又不能证明 GLM-5.3-Flash 在现有数据上可用。两类测试回答的是不同问题，不能共享一个“通过”结论。

Vitest 与 React Testing Library 验证组件，MSW 验证接口场景，Playwright 验证完整浏览器旅程。普通自动化使用确定性的测试专用模型替身，结果只标记“产品流程通过”。真实 GLM-5.3-Flash 只用于独立冒烟和正式 PoC，结果单独标记“真实模型验证通过或失败”。

测试模型替身不得进入生产构建或业务页面，不得绕过 ZIP 校验、Pydantic、证据引用、状态机和数据库约束。真实模型偶然返回成功不能代替自动化回归，自动化全绿也不能代替真实模型 PoC。
