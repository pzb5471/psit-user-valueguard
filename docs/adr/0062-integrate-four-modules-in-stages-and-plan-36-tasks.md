# 分阶段连接四个模块并以 36 张任务卡为基准

四个模块在一次大合并中首次接线，会把数据、模型、状态和页面问题混在一起。任务过大又会迫使执行者重新设计架构，无法达到一张卡一次执行即可验收的目标。

接口冻结和模块替身完成后，四名成员并行开发；集成依次执行 M1—M3、M2—M3、M4—M3、确定性 E2E、真实 GLM 冒烟和正式 PoC。首轮以 36 张任务卡规划：M1 八张、M2 十张、M3 九张、M4 九张，最终总数允许在 32—40 之间根据真实工作量调整。

每张任务卡只能有一个主要模块、一个可验收结果、一名负责人、明确文件范围、直接可执行的验收命令和至少一个失败场景。跨模块任务只允许修改接口适配层和合同测试，不允许成为含混的“大联调”任务。
