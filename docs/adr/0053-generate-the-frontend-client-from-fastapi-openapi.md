# 从 FastAPI OpenAPI 生成前端客户端合同

前后端由不同任务并行实现时，手写两份接口字段会迅速漂移。把数据库对象直接交给页面或让每个页面自行解释错误，也会破坏已经确认的业务展示边界。

FastAPI OpenAPI 是接口字段唯一来源。前端使用 `openapi-typescript` 生成并提交 TypeScript 类型，使用 `openapi-fetch` 发送请求；合同变化后必须重新生成，持续集成检查生成结果是否过期。后端先把错误映射为稳定业务错误，前端通过集中呈现层显示业务可读信息。

不手写重复请求类型，不直接序列化 ORM 到页面，不让页面组件解析供应商响应、堆栈或数据库字段。生成类型可以提交供团队同步，但不得脱离 OpenAPI 单独修改。
