# 统一由 GlmClient 接入模型供应商

产品内只有薄封装 `GlmClient` 可以导入并调用固定版本的智谱官方 `zai-sdk`。它负责从本机环境变量 `ZAI_API_KEY` 鉴权、组装 Chat Completions 请求、发送文本与获准阶段的图片、启用 JSON 输出、应用统一参数、处理规定的网络重试，并返回供应商请求编号、原始响应、Token、耗时与技术错误。

感知、归因和策略 Agent 只负责各自 Prompt、阶段输入和输出合同。`RunService` 负责阶段顺序、案例状态、输出校验、是否定向修复、程序业务规则和数据库持久化。`GlmClient` 不读取 SQLAlchemy 业务对象，不计算 RFM，不判断事件、原因或动作，也不直接更新案例状态。

这条依赖边界应由静态测试保证：Agent 和运行服务不得直接导入供应商 SDK。集中接入减少重复代码，也保证三个阶段使用同一鉴权、超时、错误分类和记录规则。
